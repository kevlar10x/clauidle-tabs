# Clauidle Tabs privacy policy

Last updated: 3 November 2026

Clauidle Tabs is a browser extension by kevlar10x. It has no server, no analytics and no accounts, and it makes no network requests. Nothing it stores leaves your browser, and nobody else receives it, including me.

## What it stores

All of this is kept in your browser's own extension storage.

Kept until you remove the extension:

- Your settings: whether each feature is on, the number of minutes, the window you picked, and the id of that window's pinned tab.
- A SHA-256 hash of the name of each tab group counted as Claude's, up to 100. This lets the extension recognise those groups after the browser restarts. The names themselves aren't stored. Switching a group off removes its hash.

Kept only until the browser closes:

- The ids of the tab groups you switched on or off, and of groups it has just recognised.
- The ids of tabs in those groups, with the time each one was last touched, so it knows which tabs are idle.
- The ids of tabs it has tried to close, so it doesn't try the same tab twice.
- The id of the window that has the focus and of the tab showing in each window, so it can send you back when Claude's tabs pull you away.

## What it reads

It reads the names, colours and ids of your tab groups, so it can list them in the settings and recognise Claude's. It reads when a tab was last used and whether a tab is pinned, active or playing sound, so it can decide what to close. It reads which window has the focus and which tab opened a new tab, so it can tell when Claude's tabs pull you away. It keeps none of those names as text.

It can't read page contents, web addresses or tab titles. It doesn't ask for those permissions.

## What it does with your data

It uses this data only to keep Claude's tab groups in the window you picked, to send you back when they pull you away, and to close the idle ones. It doesn't sell it, share it, or use it for anything else.

## Removing your data

Removing the extension deletes everything it stored.

## Changes

If this policy changes, the new version goes on this page with a new date.
